# 开发计划

## 项目约定

- 名称：新&怡
- 项目目录：E:\XinandYi
- 视觉：简约、米白背景、浅藕粉点缀、宋体标题、风景与生活照片。
- 主要入口：我们、手记、愿望。
- 当前阶段：第一里程碑，本地可操作页面原型。

## 里程碑 1：页面与交互

- [x] Next.js App Router、TypeScript、Tailwind CSS 项目与锁文件。
- [x] 登录页与两个预览身份。
- [x] 首页、恋爱天数、纪念日倒计时、近期手记、愿望摘要。
- [x] 恋爱手记列表、详情、搜索、作者筛选、发布、编辑、删除。
- [x] 双人愿望分类、筛选、完成进度、编辑与删除、生成手记。
- [x] 恋爱日期、生日与首页合照的设置入口。
- [x] 浏览器本地保存，明确标注示例内容和预览范围。
- [x] 本地运行说明、类型检查与生产构建。
- [ ] 用户视觉验收与反馈调整。

## 里程碑 2：真实账号与数据

- 设计 PostgreSQL 数据模型并使用 Prisma 管理迁移。
- 选择并接入成熟认证库，预置两个账号，关闭公开注册。
- 密码哈希、登录限流、安全 Cookie、退出与修改密码后的会话处理。
- 所有记录和照片在服务端验证身份；作者限制不能只放在界面。
- 用服务端接口替换 src/lib/store.tsx 的本地持久化。
- 增加本地预览数据导入流程，给示例内容明确的保留/丢弃选择。
- 对愿望生成手记使用事务与唯一约束，避免并发重复生成。

## 里程碑 3：私有照片与维护

- 私有 S3 兼容对象存储、带鉴权的访问地址或短期签名地址。
- 图片类型、尺寸、数量验证，缩略图与手机照片方向处理。
- 数据库与照片独立备份，验证实际恢复流程。
- 记录迁移、更新、回退与日常维护方法。
- 增加认证、权限、日期边界和主要写操作的必要自动化测试。

## 里程碑 4：部署上线

- 确定域名、服务器地区、供应商与续费预算。
- Docker Compose、Caddy、生产密钥管理。
- 若选择中国大陆服务器，安排 ICP 备案。
- 配置 DNS、HTTPS、备份、可用性检查。
- 使用真实手机网络验收，再开始正式记录。

## 本轮不包含

购买域名或服务器、远程发布、正式账号安全边界、跨设备同步、视频、地图、通知、AI 总结。当前监听 127.0.0.1，仅供本机预览。
