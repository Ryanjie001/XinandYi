## 下一里程碑：正式上线

1. 用户确定最终纪念日、封面和两人密码，完成视觉验收。
2. 确定域名与ICP备案；大陆服务器上线域名通常需要备案。
3. 准备正式数据库迁移与初始账号，不将测试数据自动复制到正式库。
4. 网站 Docker 镜像、反向代理、HTTPS、生产环境变量和最小权限 COS 凭据。
5. 生产备份/恢复、COS 版本管理或独立照片备份、照片维护定时任务和可用性检查。
6. 用两人的手机与实际移动网络验收后，开始正式记录。
