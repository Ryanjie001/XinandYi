## 实现修正

- 日期表单提交时读取 FormData，兼容日期控件和浏览器自动填充。
- 照片正在处理时禁用保存，避免丢失尚未处理完成的照片。
- 原生 dialog 内显示保存和上传反馈，避免提示被模态遮罩挡住。
- 根据 Next.js 提示补充 data-scroll-behavior 属性。
- 此 Windows 环境的 Turbopack 生产导出遇到创建 segment 目录的 EPERM。生产打包采用 Webpack 和一个构建 worker 后通过；生产输出放在 .next-production，开发输出在 .next，避免混用。

当前没有正式账号认证、服务端授权、数据库、私有云端照片存储或跨设备同步。预览数据只存在当前浏览器的 localStorage。正式上线前按 DEVELOPMENT.md 完成后续里程碑。
