# 界面设计约定

本轮方向：简约、安静、清晰，保留浅蓝与白色。

- 背景使用极浅蓝，交互区域使用白色，蓝色只用于主要按钮、选中状态和必要强调。
- 全站统一系统无衬线字体，标题通过字重与大小建立层级。
- 首页使用单张平直封面；去除拼贴、胶带、倾斜、爱心涂鸦与重复英文装饰。
- 保留记录摘要、近期手记、愿望和纪念日，减少重复文案与容器层级。
- 手记以照片和正文为主；愿望统一使用同一种卡片样式，分类通过文字区分。
- 表单、登录、详情和空状态采用一致的小圆角、细边框与留白。
- 次要文字在浅蓝表面上的对比度至少 4.5:1，键盘焦点可见，手机导航与安全区域适配保留。
- 不使用浮起动画、渐变按钮、大面积投影。投影仅保留在弹窗及账号菜单。

功能、数据库、COS 和已有记录保持原样。本轮不运行创建或删除业务记录的回归测试；使用类型检查、生产构建和桌面/手机交互检查验收。
