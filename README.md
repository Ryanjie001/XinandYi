# 新&怡 · 我们的小世界

专属于两个人的恋爱记录网站。第一里程碑：本地交互原型。

## 开发与预览

要求 Node.js 22 LTS 或更新的受支持 LTS，npm 随 Node.js 安装。

在 PowerShell 中运行：

```powershell
Set-Location E:\XinandYi
npm.cmd ci
npm.cmd run dev
```

已安装依赖时，直接运行最后一条命令。也可以双击项目根目录的「启动预览.cmd」。

打开 http://127.0.0.1:3000 。开发服务只监听本机，不会向局域网开放。

| 页面     | 地址                          |
| -------- | ----------------------------- |
| 我们     | http://127.0.0.1:3000         |
| 登录页   | http://127.0.0.1:3000/login   |
| 恋爱手记 | http://127.0.0.1:3000/journal |
| 双人愿望 | http://127.0.0.1:3000/wishes  |

## 当前可体验的功能

- 米白、灰绿、浅藕粉配色，宋体标题与留白，手机底部导航。
- 登录页选择「新」或「怡」的预览身份，右上角头像可切换。
- 设置恋爱开始日期、两人生日、首页合照。
- 恋爱天数按北京时间、开始当日为第 1 天计算；纪念日按公历每年重复，2 月 29 日在平年按 2 月 28 日展示。
- 手记发布、照片压缩、详情相册、作者筛选、文字搜索、编辑与删除。
- 愿望新增、分类、编辑、删除、完成及撤销完成、完成进度、完成后生成一篇手记。
- 上传时阻止保存，保存失败保留表单；本地存储不足显示提示。
- 弹窗支持 Escape 关闭、键盘焦点限制，按钮提供可读名称，尊重减少动态效果设置。

## 当前数据范围

这是本地体验版。没有正式身份认证、服务器数据库和云端照片存储，登录页无需密码。预览身份和作者入口限制仅用于体验交互，不能作为安全权限。

修改保存在当前浏览器的 localStorage，键为 `xin-and-yi:preview:v1`。不同浏览器、设备或来源地址不共享数据，清除网站数据会删除本地记录。不要把这个原型作为正式相册的唯一保存位置。

初始手记和愿望均为带「示例」标记的虚构内容，不代表你们的真实经历。恋爱日期和生日初始为空。照片为本地保存的 Unsplash 示例风景，详情见 docs/ASSETS.md。

## 检查与构建

```powershell
npm.cmd run typecheck
npm.cmd run build
npm.cmd start
```

生产构建采用 Webpack 和单个构建 worker，输出到 .next-production；开发输出保留在 .next。开发与生产预览默认都使用 3000 端口，启动生产预览前先停止开发服务。

## 项目结构

- `src/app`：首页、登录、手记、愿望，以及全局样式。
- `src/components`：导航、弹窗、表单、照片选择、手记卡片。
- `src/lib`：本地数据模型、状态、日期计算与照片处理。
- `public/images`：示例静态照片，不能放真实私密照片。
- `docs`：开发计划、视觉方向、验收记录与素材来源。
- `AGENTS.md`：Next.js 自动生成的开发说明。
- `.env.example`：下一阶段环境变量的占位说明。

依赖已用 package-lock.json 锁定，使用 npm ci 复现。真实密钥、环境文件、浏览器运行数据和构建产物不提交 Git。
